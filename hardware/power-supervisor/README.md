# Power Supervisor Hardware

Planned scope includes a fused 16 V-class Highland input, reverse-polarity and
transient protection, no-backfeed behavior, current/thermal measurement,
undervoltage cutoff, low sleep current, and orderly compute control.

The display schematic's named 12V net is not an accessory-input specification.
Thresholds remain unpopulated until bench and Tesla-revision evidence exists.
