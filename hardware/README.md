# Hardware

Original CERN-OHL-S-2.0 hardware will be separated into video bridge, safety and
power supervision, touch, physically listen-only CAN, revision-specific
harnesses, and enclosure/thermal work.

There is no released PCB or road-ready harness yet. Every powered design must
have a reviewed safe-state analysis, source schematics, design-rule report,
manufacturing files, and end-of-line fixture.
