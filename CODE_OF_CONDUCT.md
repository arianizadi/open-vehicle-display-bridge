# Code of Conduct

We collaborate with curiosity, precision, and respect. Challenge claims with
evidence, not people. Welcome newcomers, disclose uncertainty, credit prior
work, protect private vehicle data, and stop an experiment when someone raises
a credible safety concern.

Harassment, intimidation, discriminatory behavior, doxxing, unsafe pressure,
and knowingly misrepresenting test results are not acceptable.

Report conduct concerns privately through the repository owner's GitHub profile.
The maintainers may remove content or participation that threatens people,
privacy, project integrity, or safety.
